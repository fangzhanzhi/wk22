02 / FUNCTION & SCENARIO

02整机功能与运行场景定义

安全分析的起点是「这台 machine 要在什么条件下做什么」。陆地航母是全球首个量产分体式飞行汽车：陆行体（母体）负责地面行驶与为飞行体补能，飞行体（子体）为六桨六轴双涵道纯电 eVTOL。分体式构型把飞行与地面场景解耦，本身即是一种安全设计选择。

🚗

陆行体（母体）

  • 3 轴 6 轮，车长约 5.5 m，可进标准车位/地下车库
  • 全域 800V 碳化硅高压增程平台，CLTC 续航 > 1000 km
  • 行驶/停车时为飞行体充电，支持 5–6 次飞行任务
  • 普通 C 类驾照即可驾驶（地面法规体系）
🛩

飞行体（子体）

  • 六桨六轴双涵道构型，碳纤维可折叠旋翼/机身
  • 270° 全景双人座舱，可完全收纳于汽车尾箱
  • 纯电驱动，数分钟内自动展开与锁止
  • 垂直起降，无需跑道；最高速度约 200 km/h（口径不一）

基于运行设计条件（ODC）的四类场景

A

地面行驶

道路交通常规风险；能量管理、高压系统安全、制动与转向冗余。

B

分合 / 展开

高风险转换态：机械锁止是否到位、旋翼展开完整性、人因误操作。

C

低空飞行

起降/悬停/巡航；动力失效、碰撞避让、气象突变、空域冲突。

D

应急状态

单/多旋翼失效、失控、火情、迫降；降落伞与自主着陆兜底。

关键洞察：分体式设计把"飞行"与"地面"解耦，让各自采用最优动力方案（增程保续航、纯电保安全与低噪），避免了单一平台兼顾两场景的工程妥协——这本身就是教材所强调的"通过分析功能与场景，选择系统架构"的正向设计思路。（ch5 p36 正向设计 / p85 基于场景的安全开发）

04 / SAFETY ANALYSIS METHODS

04安全分析方法：FTA 故障树与 STPA

教材指出民航领域成熟的分析工具包括故障树（FTA）、共因分析（CCA）、事件树（ETA）、蝴蝶结（Bow-Tie）、贝叶斯网络（BBN）等；对飞行汽车这类"人-机-环境"耦合系统，还需 STPA 这种基于控制结构的系统理论方法。下面以「坠机」为顶事件做故障树演示。

矩形=顶/中间事件AND/OR=逻辑门圆形=基本事件紫框=共因约束
🕸

STPA：从控制结构找不安全行为

把飞行器抽象为「人—ADS—飞行器平台—环境」控制回路。STPA 不只关注部件失效，更关注控制动作缺失/错误/时序不当（如飞控未发出避障指令、模式切换反馈延迟），适用于高度自动驾驶的飞行体。

🎗

Bow-Tie：把预防与缓解连起来

以「电池热失控」为顶事件：左侧预防屏障（BMS 监控、热隔离、阻燃材料）→ 顶事件 → 右侧缓解屏障（不扩散设计、迫降、灭火、撤离）。与 FTA/ETA 结合，直观展示屏障完整性管理。（ch4 p39 Bow-Tie）

05 / SAFETY ARCHITECTURE

05系统安全架构设计：冗余与容错

教材给出典型安全架构（1oo1、1oo2、2oo2、1oo3、2oo3、1oo2D）与「三重冗余体系：飞控、能源、通信」。陆地航母采用双备份飞控 + 三冗余动力 + 多余度通信，并配备行业罕见的低空整机降落伞，体现了"单点故障不影响安全、多点故障仍能迫降"的纵深防御思想。

① 飞控冗余 · 双备份 + 2oo2 比较

主飞控 A∥备份飞控 B→2oo2 表决

每套飞控有独立备份，任一失效时另一套立即接管；结合 3 余度飞控导航（教材所述"多余度传感"），避免共因失效。

② 动力冗余 · 六旋翼 + 三余度

旋翼 1–6→失效 2 副仍可控

六轴六桨双涵道构型，即使 2 副旋翼失效，控制系统毫秒级重构保持稳定并安全着陆；三冗余动力架构提升容错上限。

③ 能源 / 通信冗余

能源 A/B高低压双路通信多链路

2 余度动力能源 + 2 余度高低压供电 + 多余度通信；电池 BMS 双冗余，预留 ≥20% 安全电量保障备降。

④ 最后防线 · 整机弹道降落伞

全机开伞 @ 50 m→5.2 m/s 缓降

当所有推进失效时自动弹射开伞；最低工作高度约 50 m（行业通常需 200 m 以上），为低空城市运行提供关键兜底。

为何这样设计？航空安全的哲学是"不允许单点故障导致灾难"。教材强调 10⁻⁹ 的失效概率必须靠冗余架构与共因分析（CCA）共同实现——不是简单地"多加一套"，而是要保证备份之间独立、多样、可检测，否则主备同源反而形成共因失效。（ch5 p15、p87 典型安全架构与 CCA）

06五大安全支柱在飞行体上的落地

教材将自动驾驶安全系统工程归纳为五大支柱：被动安全、功能安全、预期功能安全（SOTIF）、行为安全、信息安全。这套框架同样适用于飞行汽车。雷达图展示五维度成熟度（课堂分析性评分），右侧逐项给出针对陆地航母的具体分析。

被动安全 Passive Safety
crashworthiness / 整机伞
多维碰撞安全（纵/横/垂），碳纤维机身吸能、约束系统；整机弹道降落伞提供坠毁前的最后保护。（ch4 p38 多维 crashworthiness）

07 / SPECIALIZED DESIGN

07专项安全设计：电池、分合机构与环境

对应教材安全工程的硬件、软件、电气/机械/化学安全设计环节。其中动力电池是 eVTOL 的"最难一关"——能量密度、功率与安全三者必须同时满足，且遵循航空"零容错"铁律。

🔋

动力电池安全（化学 / 热）

  • 灾难级故障率 ≤ 10⁻⁹ / 飞行小时（载人）（ch5 p15 / 电池路线图2025）
  • 单电芯热失控不扩散，包表面温度 ≤ 150℃，不起火不爆炸
  • BMS 双冗余，电压/温度/电流毫秒级监控，预留 ≥20% 备降电量
  • 参照 RTCA DO-311A / DO-160G：加热、针刺、短路、冲击、15 m 跌落等严苛测试
  • 宽温域 -40~55℃；当前能量密度 280–320 Wh/kg，仍是核心瓶颈
⚙

分合机构与结构安全（机械）

  • 机械 + 电子双重锁止，状态反馈闭环确认后再允许起飞
  • 旋翼数分钟自动展开/折叠，展开完整性检测（防呆设计）
  • 碳纤维可折叠旋翼与机身：轻量化 + 抗振 + 碰撞吸能
  • 涵道设计降低旋翼外露风险，保护周边人员
💻

飞控软件安全（软件）

  • 按航空 DO-178C 研制保证等级开发，需求—设计—代码—测试可追溯
  • 形式化验证与 diversity 设计，抑制共因软件错误
  • 失效-安全/失效-运行（fail-safe / fail-operational）状态机
  • 升级管理（参照 UN-R156 思路），防止 OTA 引入新风险
🌡

环境适应性与极端工况

  • 已通过 -35℃ 极限试炼（汇天公开信息）
  • 飞前智能天气评估，规避雷暴/强风/暴雨超出包线
  • 低空 1000 m 以下运行，280°/270° 态势感知 + 碰撞预警
  • 高压互锁、绝缘监测、短路与供电保护（电气安全）
核心矛盾：电池要同时做到"高能量密度（飞得远）+ 高功率（能起降）+ 绝对安全（不起火）"，而航空零容错标准（10⁻⁹）比车规（10⁻⁵）严苛一万倍。何小鹏明确表示"飞行汽车的安全标准必须向航空工业看齐"。这正是本产品从车规级迈向航规级必须跨越的鸿沟。（教材 ch5 p19/p21；chinaevtol.org 2026）
08 / AIRWORTHINESS & STANDARDS

08适航认证与法规标准

设计安全（Design Safety）必须经适航审定"实证考场"证明，才能转化为运行安全。飞行汽车作为颠覆性产品，全球都处在"个案突破 → 体系构建"的过渡期。教材以 TC / PC / AC 三证为主线，此处结合陆地航母的取证进展分析。

📐

TC · 型号合格证

设计阶段：确认设计安全、可行，适用于航空运营，是投产与注册前提。陆地航母已获 CAAC 型号合格证（设计安全认证）。（ch5 p28；来源口径需以局方公告为准）

🏭

PC · 生产许可证

生产阶段：授权批量生产，要求全流程制造与质量控制能力。汇天广州工厂规划年产能 1 万台，正推进 PC 取证。（ch5 p28）

🚀

AC · 适航证 / OC 运营

运行阶段：审核持续安全运行能力（飞行人员、维护、运行程序）。分体式按地面/飞行双模式分别管理。（ch5 p28）

09安全测试验证与运行安全论证

安全不能只停留在纸面设计。教材以 V 模型描述"左侧开发分解、右侧集成验证"，并以安全论证（GSN / SACM）回答"我们凭什么说它安全"。陆地航母已进入小批量试产与多机试飞阶段，正用海量试飞数据完成安全证明。

🔬

V 模型左侧：正向安全开发

基于模型的功能定义 → ODC 场景分析 → 整机 HARA（HARA/FHA/STPA）→ 系统安全需求 → 组件安全分析（FMEDA/CAE）→ 安全设计实现。每一步输出可追溯的安全需求。

10 / CONCLUSION

10分析结论与展望

综合以上系统安全工程分析，陆地航母通过分体式架构解耦场景、以多重冗余与整机降落伞构建纵深防御，在设计层面体现出对标航空级安全的明确意图；但要从"设计安全"走向"规模化运行安全"，仍需在电池、ODD、适航体系与运行数据上持续投入。

1

架构层面

分体式是聪明的工程折中，把"飞"与"行"各自优化；冗余架构与低空伞系统构成多级容错，符合航空纵深防御原则。

2

方法层面

需用 HARA/STPA/FTA/CCA/FMEA 全流程工具，而非单点测试，去证明 10⁻⁹ 的系统级安全目标；共因失效是关键。

3

运行层面

安全是"设计+验证+运行论证"的闭环；空域管理、人员培训、应急体系与标准完善，与飞行器本身同等重要。

总评：陆地航母代表了中国飞行汽车从"能飞"走向"能安全载人或载物常态化运营"的积极探索。以教材的安全系统工程视角看，它已具备较完整的冗余设计骨架与安全文化，正处于用适航审定与试飞数据把"纸面安全"转化为"可论证安全"的关键阶段。其最终安全水平，取决于能否在航空级标准下完成全生命周期的验证与运行闭环。
